# Тracker_01 — Структура PHP-приложения (план)

Стек (заказ): PHP 8.0 + MySQL 8.0. Функционал по `Tracker_01/info/tz.md`.
Принципы: простой код, понятный клиенту (в заказе клиент упоминает знание PHP), без фреймворков,
максимально простой front controller. Разделы экранов — по tz.md разд. 10.

## Предлагаемая структура каталога `app/`

```
app/
├── public/                  # DOCUMENT_ROOT (php -S public -t ... или корень
│   ├── index.php            # точка входа (front controller / router)
│   ├── assets/              # css/js/img (статик)
│   │   ├── css/app.css
│   │   └── js/app.js        # канбан drag&drop, формы
│   └── favicon.svg
├── src/
│   ├── db.php               # подключение PDO (MySQL), локальные креды в config
│   ├── auth.php             # сессия, вход/выход, текущий пользователь
│   ├── helpers.php          # вспомогательные функции (redirect, e(), flash)
│   └── permissions.php      # проверка прав по ролям (tz.md 7.1)

│   ├── layout.php           # общий шаблон (меню/шапка/уведомления) + адаптив
│   ├── login.php            # страница входа (7.Авторизация)
```

## Роутинг (минимальный front controller)

`public/index.php` разбирает `?page=` (или path) → подключает нужный контроллерный скрипт из `src/`,
рендерит `views/…`. SSR-подход: каждый экран — PHP-шаблон с данными из БД.

## Авторизация и роли

- `src/auth.php`: `session_start()`, логин по email+паролю (`password_verify`), `$_SESSION['user_id']`,
  сохранение авторизации после обновления; выход.
- `src/permissions.php`: функции `can_manage_users()`, `can_edit_project()`, `can_move_task()` и т.п.
  по матрице прав tz.md разд. 7.1.
- Разграничение доступа к проектам: проверять членство через `project_members`.

## Канбан (12)

`views/kanban.php` + `js/app.js`: 5 колонок по `tasks.status` (backlog…done),
drag & drop обновляет статус через AJAX-эндпоинт (PHP сохраняет в БД + пишет activity_log).

## Очередность сборки (по уроку: сначала функциональное ядро)

1. `config.php` + `src/db.php` + подключение к БД (после импорта schema/demo).
2. `auth` (вход/выход) — проверить по чек-листу.
3. Списки: dashboard, my_tasks, projects.
4. CRUD задач (форма), назначение исполнителя.
5. Канбан с drag&drop.
6. Комментарии, вложения-ссылки, история.
7. Уведомления, профиль, админ-панель.
8. Права по ролям (сквозная проверка).
9. Тестирование/итерации + скриншоты (тетрадь).
