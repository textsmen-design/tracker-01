# Tracker_01 — MVP «Простая система учёта задач»

Учебный кейс №1 (FGIp07): серверная система учёта задач для небольшой команды
по реальному заказу freelance.ru #1645675. Стек: **PHP 8 + MySQL 8**, чистый CSS/JS.

## Требования

- PHP 8.0+ (модули: `pdo_mysql`)
- MySQL 8.0+
- Любой веб-сервер, поддерживающий PHP (в разработке — встроенный `php -S`)

## Запуск (локально)

```bash
# 1) В config.php указать доступы к БД (по умолчанию root/пустой пароль на 127.0.0.1).
# 2) Импортировать схему и демо-данные (см. ../db/README.md).
# 3) Запустить встроенный сервер из каталога public/:
cd public
php -S 127.0.0.1:8080
# 4) Открыть http://127.0.0.1:8080
```

## Структура

```
app/
  config.php          — доступы к БД (редактировать)
  public/             — document root (php -S нужно запускать отсюда)
    index.php         — front-controller
    assets/           — css, js
  src/
    db.php            — PDO (один пул)
    helpers.php       — e(), redirect, flash, статусы, даты
    auth.php          — сессия, вход/выход
    permissions.php   — проверка прав по ролям (магалица прав, tz.md 7.1)
    actions.php       — POST-действия (задачи, статусы, комментарии, пользователи…)
    pages/            — экраны (mysql): dashboard, my_tasks, projects, project, task, …
    partials/         — карточка задачи, форма пользователя
  views/              — layout, fullpage, login, 404
```

## Права (кратко)

- **Админ** — всё: пользователи, проекты, любые задачи и комментарии.
- **Руководитель** — создаёт задачи в своих проектах, меняет статусы, ведёт проект, видит сводку по команде.
- **Сотрудник** — видит свои задачи и проекты, может менять статус назначенной ему задачи, комментировать.

## Статус изменений

MVP собирается в рамках учебного кейса (без фреймворков, пароли — очевидные,
только для демо). Перед публикацией нужны: смена демо-паролей, обработка
загрузки вложений, интернационализация — см. Tracker_01/info/tz.md разд. «Неизвестно».
