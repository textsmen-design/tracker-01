# BRANDBOOK — Stopa (учебная айдентика трекера Tracker_01)

Автор: учебная разработка для кейса №1 (симуляция без копирования чужих брендов).
Дата: 20.09.2026.

## Идея и позиционирование

Трекер задач для небольшой команды службы выгула и ухода за питомцами.
Продукт управляет «следами» дел команды: каждая задача — шаг, который нужно отследить
и довести до конца. Название **Stopa / Стопа** (след, лапа, шаг) вписывается в тему
просто и без перегруза.

## Знак (логотип)

- **Форма:** геометрическая «лапа» — 4 пальца-эллипса, подушечка и «пятая» падающая
  точка (след завершённого шага). Знак нарисован специально для кейса простыми
  SVG-примитивами, «стоковая лапа» из фотобанков не используется.
- **Иконка-плитка** (favicon): лапа на скруглённом квадрате Trail Green.
- **Файлы:** `app/public/assets/img/logo-mark.svg` (знак), `favicon.svg` (плитка),
  `pattern.svg` (паттерн следов для фонов).

| Основной | Trail Green | `#1E8A5A` | кнопки, активные пункты, акценты |
| Тёмный | Deep Forest | `#0F4A33` / `#0B3A27` | сайдбар, заголовки |

Соотношение: ~60 % тёплый фон / 30 % зелёный / 10 % коралл.

## Типографика

- **Baloo 2** (Google Fonts, OFL) — фирменное слово, заголовки бренда.
- **Nunito** (Google Fonts, OFL) — интерфейсный шрифт, скруглённый и дружелюбный.
- Офлайн-фолбэк на системные шрифты.

## Стиль интерфейса

Скругление карточек 12–14 px, мягкие тени, светлый тёплый фон, тёмно-зелёный сайдбар.
Статусы и приоритеты — цветные pill-бейджи, палитра которых введена в CSS-токены (`app/public/assets/css/app.css`).

## Применение в коде

- `app/config.php` → `APP_NAME = 'Stopa'`.
- `app/views/layout.php` — пункт бренда в сайдбаре (знак + «Stopa · трекер задач»), favicon, шрифты.
- `app/views/login.php` — логотип + слово + таглайн «Трекер задач для команды по выгулу и уходу за питомцами».
- `app/public/assets/css/app.css` — CSS-переменные айдентики.

## Источники референсов (только направление, не копировались)

- Обзор айдентики служб выгула собак (Contra: кейсы дог-волкер-брендов) — направление: дружелюбная типографика, тепло, активность.
- Sniff Design Studio — Queen Anne Dog Walking Branding: зелёные/тёплые тона, простота знака.
- Вывод для дизайна: скруглённые гуманистичные шрифты (Nunito/Quicksand/Baloo 2), избегать «стоковой лапы»,
  зелёный = природа/активность, коралл = энергия; знак должен читаться в малом размере (favicon).

Шрифты Baloo 2 и Nunito распространяются по SIL OFL 1.1 (Google Fonts). Знак, палитра и композиция —
собственная разработка кейса.
