# Stopa · Tracker_01 — трекер задач для команды по уходу за питомцами

Учебно-портфолио проект (кейс №1, трек «Фриланс»). Простой трекер задач на чистом **PHP + MySQL**
с брендингом **Stopa** — фирменная айдентика (знак «лапа», палитра Trail Green / Warm Coral /
Warm Sand, шрифты Baloo 2 + Nunito, favicon и паттерн) для демо службы выгула и ухода за питомцами.

> Это учебная симуляция: заказ с биржи выполняется без отклика заказчику, для тренировки и портфолио.

## Возможности

- Вход/выход по ролям: **админ / руководитель / сотрудник** (сессии + CSRF-защита POST).
- Проекты и участники, задачи с исполнителем, сроком и приоритетом.
- Канбан **5 колонок** (backlog → planned → in_progress → review → done) с drag&drop.
- Списки с фильтрами и поиском, просроченные задачи выделяются.
- Комментарии (свои — правка/удаление, админ — любые), вложения-ссылки, история изменений.
- Внутренние уведомления (бейдж в меню и колокольчик).
- Адаптивная вёрстка (ПК/смартфон), тёмное фирменное меню.
- Матрица прав: доступ к проектам только участникам команды.

## Стек

PHP 8 (MVP разрабатывается на MariaDB 10.4, совместимой с MySQL 8 — требование ТЗ) · чистый HTML/CSS/JS · без фреймворков · Google Fonts (Baloo 2, Nunito).

## Запуск локально

```bash
# 1) подготовить БД (MariaDB/MySQL), схема и демо-данные:
mysql -u root < db/schema.sql
# в demo_data.sql заменить плейсхолдеры {HASH_*} на password_hash('demo123', PASSWORD_DEFAULT)
mysql -u root simple_tasks < db/demo_data.sql

# 2) приложение (docroot — app/public):
php -S 127.0.0.1:8080 -t app/public
```

Под macOS (XAMPP) всё поднимается одной командой: `scripts/start_dev.sh`
(поднимет MariaDB и PHP на `http://127.0.0.1:8080`, повторный запуск безопасен).

## Структура

```
app/
  public/         # docroot: index.php (роутер), assets/ (css, js, img)
  src/            # db, auth, helpers, permissions, pages, partials
  views/          # layout (меню), login, dashboard, my_tasks, project, team, ...
  config.php      # креды БД (локально, не в git)
db/               # schema.sql + demo_data.sql
doc/              # test_report.md, checklist_screens.md, screenshots/ (реальные)
info/             # ТЗ, промпты, материалы заказа
scripts/          # start_dev.sh (локальный запуск окружения)
```

## Документация

- `info/tz.md` — техническое задание; `info/brandbook.md` — айдентика Stopa.
- `doc/test_report.md` — регрессия по критериям приёмки ТЗ (14/14) + регрессия после брендинга.
- `doc/screenshots/` и `doc/screenshots/branded/` — реальные скриншоты.
